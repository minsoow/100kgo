# 협회 홈페이지 게시판 사용법

한국온라인해외직판협회 담당자용 안내입니다.
공지사항과 재무고시 자료를 직접 등록·수정·삭제하실 수 있습니다.

---

## 1. 로그인

1. 브라우저 주소창에 **`https://협회도메인/admin`** 을 입력합니다.
2. 전달받은 **아이디**와 **비밀번호**를 입력하고 [로그인]을 누릅니다.

> 비밀번호를 잊으셨거나 변경이 필요하면 제작사(이이공이)로 연락 주세요.
> 로그인 상태는 8시간 후 자동으로 해제됩니다.

---

## 2. 화면 구성

로그인하면 **게시글 관리** 화면이 나타납니다.

| 위치 | 기능 |
|---|---|
| 우측 상단 [+ 새 글 작성] | 새 글 등록 |
| 목록의 글 제목 | 클릭하면 수정 화면으로 이동 |
| [보기] | 홈페이지에 실제로 보이는 모습 확인 (새 창) |
| [수정] / [삭제] | 글 수정 / 삭제 |
| 우측 상단 [홈페이지 보기] | 협회 홈페이지 새 창으로 열기 |
| 우측 상단 [로그아웃] | 로그아웃 |

---

## 3. 새 글 등록하기

### ① 분류 선택
- **공지사항** — 협회 소식, 행사 안내 등
- **재무고시** — 결산서류 등 법령에 따른 공고

### ② 제목 입력
목록에 표시되는 제목입니다. (최대 300자)

예) `2025년도 결산서류 등의 공고`

### ③ 상단 고정 (선택)
**‘목록 상단에 고정’** 을 체크하면 그 글이 목록 맨 위에 ‘중요’ 표시와 함께 항상 노출됩니다.
중요 공지에만 사용하시고, 기간이 지나면 체크를 해제해 주세요.

### ④ 내용 작성
글쓰기 영역에 내용을 입력합니다. 상단 버튼으로 서식을 지정할 수 있습니다.

| 버튼 | 기능 |
|---|---|
| **B** / *I* / U / S | 굵게 / 기울임 / 밑줄 / 취소선 |
| 제목 · 소제목 | 문단 제목 스타일 |
| • 목록 / 1. 목록 | 글머리 기호 / 번호 목록 |
| 인용 | 인용문 스타일 |
| 좌 · 중 · 우 | 문단 정렬 |
| 링크 | 선택한 글자에 링크 걸기 |
| 구분선 | 가로줄 삽입 |

> **링크 넣는 법**: 링크를 걸 글자를 마우스로 드래그해 선택한 뒤 [링크] 버튼을 누르고 주소를 입력합니다.
> 링크를 없애려면 같은 방법으로 [링크]를 누른 뒤 주소를 지우고 확인을 누르세요.

> 다른 문서(한글·워드)에서 복사해 붙여넣어도 됩니다. 서식이 흐트러지면 각 버튼으로 다시 정리해 주세요.

### ⑤ 첨부파일 등록
[파일 선택] 버튼을 눌러 파일을 고릅니다. 여러 개를 한 번에 선택할 수 있습니다.

- 가능한 형식: **PDF, 이미지(JPG·PNG), 한글(HWP)**
- 파일당 최대 **20MB**, 글당 최대 **10개**
- 잘못 올린 파일은 목록 오른쪽 [삭제]로 제거합니다.

> **재무고시는 PDF 첨부를 권장합니다.** 어느 기기에서나 동일하게 보이고, 별도 프로그램 없이 열람할 수 있습니다.

### ⑥ 등록
[등록] 버튼을 누르면 저장되고 목록으로 돌아갑니다. 홈페이지에는 **즉시 반영**됩니다.

---

## 4. 글 수정하기

1. 목록에서 수정할 글의 [수정]을 누릅니다.
2. 내용을 고친 뒤 [수정 완료]를 누릅니다.

> 첨부파일은 **저장 시점의 목록이 그대로 반영**됩니다.
> 수정 화면에서 파일을 [삭제]하고 저장하면 그 파일은 완전히 삭제됩니다.

---

## 5. 글 삭제하기

목록에서 [삭제]를 누르고 확인창에서 [확인]을 누릅니다.

> ⚠️ **삭제한 글과 첨부파일은 되돌릴 수 없습니다.** 삭제 전에 다시 한 번 확인해 주세요.
> 잠시 내리고 싶은 글이라면 삭제 대신 내용을 수정해 두는 방법도 있습니다.

---

## 6. 자주 묻는 질문

**Q. 글을 올렸는데 홈페이지에 안 보여요.**
브라우저 새로고침(F5)을 해보세요. 그래도 안 보이면 관리자 화면 목록에 글이 있는지 확인해 주세요.

**Q. 파일이 업로드되지 않아요.**
용량(20MB)과 형식(PDF·이미지·HWP)을 확인해 주세요. 큰 PDF는 분할하거나 압축하면 됩니다.

**Q. 로그인 화면으로 자꾸 돌아가요.**
로그인 후 8시간이 지나면 자동 로그아웃됩니다. 다시 로그인해 주세요.

**Q. 비밀번호를 여러 번 틀렸더니 로그인이 안 돼요.**
보안을 위해 10분 동안 8회까지만 시도할 수 있습니다. 잠시 후 다시 시도해 주세요.

**Q. 협회 소개글이나 회원사 정보를 바꾸고 싶어요.**
그 부분은 게시판이 아니라 홈페이지 본문 영역이라 제작사(이이공이)를 통해 수정합니다.
납품 후 1개월 이내의 자료 반영은 하자보수 범위에서 처리해 드립니다.
