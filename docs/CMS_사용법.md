# 협회 홈페이지 게시판 사용법

한국온라인해외직판협회 담당자용 안내입니다.
공지사항과 재무고시 자료를 직접 등록·수정·삭제하실 수 있습니다.

---

## 1. 로그인

1. 브라우저 주소창에 **`www.100kgo.kr/admin`** 을 입력합니다.
2. 전달받은 **아이디**와 **비밀번호**를 입력하고 [로그인]을 누릅니다.

> 비밀번호를 잊으셨거나 변경이 필요하면 제작사(이이공이)로 연락 주세요.
> 로그인 상태는 8시간 후 자동으로 해제됩니다.

---

## 2. 화면 구성

로그인하면 **게시글 관리** 화면이 나타납니다.

| 위치 | 기능 |
|---|---|
| 우측 상단 [+ 새 글 작성] | 새 글 등록 |
| 목록의 글 제목 | 클릭하면 수정 화면으로 이동 |
| [보기] | 홈페이지에 실제로 보이는 모습 확인 (새 창) |
| [수정] / [삭제] | 글 수정 / 삭제 |
| 우측 상단 [홈페이지 보기] | 협회 홈페이지 새 창으로 열기 |
| 우측 상단 [로그아웃] | 로그아웃 |

---

## 3. 새 글 등록하기

### ① 분류 선택
- **공지사항** — 협회 소식, 행사 안내 등
- **재무고시** — 결산서류 등 법령에 따른 공고

### ② 제목 입력
목록에 표시되는 제목입니다. (최대 300자)

예) `2025년도 결산서류 등의 공고`

### ③ 상단 고정 (선택)
**‘목록 상단에 고정’** 을 체크하면 그 글이 목록 맨 위에 ‘중요’ 표시와 함께 항상 노출됩니다.
중요 공지에만 사용하시고, 기간이 지나면 체크를 해제해 주세요.

### ④ 내용 작성
글쓰기 영역에 내용을 입력합니다. 상단 버튼으로 서식을 지정할 수 있습니다.

| 버튼 | 기능 |
|---|---|
| **B** / *I* / U / S | 굵게 / 기울임 / 밑줄 / 취소선 |
| 제목 · 소제목 | 문단 제목 스타일 |
| • 목록 / 1. 목록 | 글머리 기호 / 번호 목록 |
| 인용 | 인용문 스타일 |
| 좌 · 중 · 우 | 문단 정렬 |
| 링크 | 선택한 글자에 링크 걸기 |
| 구분선 | 가로줄 삽입 |

> **링크 넣는 법**: 링크를 걸 글자를 마우스로 드래그해 선택한 뒤 [링크] 버튼을 누르고 주소를 입력합니다.
> 링크를 없애려면 같은 방법으로 [링크]를 누른 뒤 주소를 지우고 확인을 누르세요.

> 다른 문서(한글·워드)에서 복사해 붙여넣어도 됩니다. 서식이 흐트러지면 각 버튼으로 다시 정리해 주세요.

> **글 속에 이미지 넣기**: 이미지를 넣고 싶은 위치를 클릭한 뒤 **[🖼 이미지]** 버튼을 누르고 파일을 고릅니다.
> 사진이 글 중간에 그대로 보입니다. 행사 포스터나 안내 그림처럼 **글과 함께 보여줄 사진**에 쓰세요.
>
> - 가능한 형식: JPG · PNG · WEBP · GIF / 장당 최대 **8MB**
> - 큰 사진도 화면 폭에 맞게 자동으로 줄어듭니다. 휴대폰에서도 잘립니다.
> - 지우려면 에디터에서 사진을 클릭해 선택한 뒤 `Delete` 키를 누릅니다.

**첨부파일과 본문 이미지의 차이**

| | 본문 이미지 [🖼 이미지] | 첨부파일 [파일 선택] |
|---|---|---|
| 보이는 방식 | 글 중간에 **사진으로 표시** | 글 아래 **내려받기 목록** |
| 쓰임새 | 포스터 · 안내 그림 · 현장 사진 | 재무제표 · 신청서 · 공문 |
| 형식 | 이미지만 | PDF · 워드 · 한글 · 이미지 |

### ⑤ 첨부파일 등록
[파일 선택] 버튼을 눌러 파일을 고릅니다. 여러 개를 한 번에 선택할 수 있습니다.

- 가능한 형식: **PDF, 워드(DOC·DOCX), 한글(HWP·HWPX), 이미지(JPG·PNG)**
- 지원서처럼 **받는 분이 직접 채워 넣어야 하는 양식**은 PDF 로 바꾸지 말고 워드·한글 원본 그대로 올려 주세요.
- 파일당 최대 **20MB**, 글당 최대 **10개**
- 잘못 올린 파일은 목록 오른쪽 [삭제]로 제거합니다.

> **재무고시는 PDF 첨부를 권장합니다.** 어느 기기에서나 동일하게 보이고, 별도 프로그램 없이 열람할 수 있습니다.

### ⑥ 등록
[등록] 버튼을 누르면 저장되고 목록으로 돌아갑니다. 홈페이지에는 **즉시 반영**됩니다.

---

## 4. 글 수정하기

1. 목록에서 수정할 글의 [수정]을 누릅니다.
2. 내용을 고친 뒤 [수정 완료]를 누릅니다.

> 첨부파일은 **저장 시점의 목록이 그대로 반영**됩니다.
> 수정 화면에서 파일을 [삭제]하고 저장하면 그 파일은 완전히 삭제됩니다.

---

## 5. 글 삭제하기

목록에서 [삭제]를 누르고 확인창에서 [확인]을 누릅니다.

> ⚠️ **삭제한 글과 첨부파일은 되돌릴 수 없습니다.** 삭제 전에 다시 한 번 확인해 주세요.
> 잠시 내리고 싶은 글이라면 삭제 대신 내용을 수정해 두는 방법도 있습니다.

---

## 6. 팝업 관리

첫 화면에 뜨는 안내창입니다. 행사 모집이나 긴급 공지처럼 **꼭 봐야 하는 소식**에 씁니다.

상단 메뉴에서 **[팝업]** 을 누르면 관리 화면으로 갑니다.

### 새 팝업 만들기

**① 팝업 이름**
관리 목록에서 구분하기 위한 이름입니다. **방문자에게는 보이지 않습니다.**

**② 팝업 이미지** — *가장 중요합니다*
[이미지 선택] 을 눌러 파일을 고릅니다.

- **정사각형 이미지를 준비해 주세요.** (예: 800 × 800)
- JPG · PNG · WEBP · GIF / 최대 5MB
- 정사각형이 아니면 경고가 뜨지만 그대로 등록할 수도 있습니다

> **팝업에 넣을 내용은 이미지 안에 다 들어가야 합니다.** 제목·날짜·신청 방법 등을
> 이미지로 만들어 올리시면 됩니다. 홈페이지가 글자를 따로 얹어주지 않습니다.

> ⚠️ **작은 글씨를 넣지 마세요.**
> 800 × 800 으로 만든 이미지는 화면에서 **448 × 448 로 줄어들어** 보입니다.
> 이미지 안의 글자도 **절반 크기**가 되므로, 원본에서 작아 보이는 글자는
> 화면에서 읽히지 않습니다.
>
> - 원본 800px 기준으로 **글자 높이 26px 이상**을 권장합니다 (화면에서 13px)
> - 넣을 내용은 **3~5줄로 줄이시고**, 자세한 안내는 연결된 게시글에 담으세요
> - 만든 이미지를 **가로 450px 정도로 줄여 보고** 다 읽히는지 확인하시면 확실합니다

**③ 이미지 설명** (선택)
눈이 불편한 분이 쓰는 화면 읽기 프로그램이 읽어 주는 문장입니다.

**④ 연결 주소** (선택)
방문자가 이미지를 클릭하면 이동할 주소입니다. 카페 게시글 주소 등을 넣으시면 됩니다.
비워 두면 클릭해도 아무 일이 없습니다.

**⑤ 노출 기간** (선택)

> **행사 안내라면 종료 일시를 꼭 넣어 두세요.** 나중에 내리는 것을 잊어도 자동으로 사라집니다.
> 비워 두면 직접 끌 때까지 계속 보입니다.

**⑥ 지금 사용**
**이 칸을 체크해야 방문자에게 보입니다.** 미리 만들어 두고 나중에 켜셔도 됩니다.

### 목록 화면 읽는 법

각 팝업 오른쪽에 지금 상태가 표시됩니다.

| 표시 | 뜻 |
|---|---|
| **지금 노출 중** | 방문자에게 보이고 있습니다 |
| **○월 ○일 부터** | 켜져 있지만 시작일이 아직 안 됐습니다 |
| **기간 종료됨** | 켜져 있지만 기간이 지나 안 보입니다 |
| **사용 안 함** | 꺼져 있습니다 |

[사용 중] / [사용 안 함] 버튼을 누르면 **바로 켜고 끌 수 있습니다.**

### 알아두실 점

- **팝업은 한 번에 하나만 보입니다.** 여러 개를 켜 두면 가장 최근에 수정한 것이 나타납니다.
- 방문자가 **[다시 보지 않기]** 를 누르면 그 사람에게는 더 이상 보이지 않습니다.
  다만 **팝업을 수정하면 다시 보입니다.**
- **[닫기]** 나 **X** 로 닫은 사람에게는 다음에 다시 보입니다.
- 삭제한 팝업과 이미지는 **되돌릴 수 없습니다.**

## 7. 자주 묻는 질문

**Q. 글을 올렸는데 홈페이지에 안 보여요.**
브라우저 새로고침(F5)을 해보세요. 그래도 안 보이면 관리자 화면 목록에 글이 있는지 확인해 주세요.

**Q. 파일이 업로드되지 않아요.**
용량(20MB)과 형식(PDF·워드·한글·이미지)을 확인해 주세요. 큰 PDF는 분할하거나 압축하면 됩니다.

**Q. 로그인 화면으로 자꾸 돌아가요.**
로그인 후 8시간이 지나면 자동 로그아웃됩니다. 다시 로그인해 주세요.

**Q. 비밀번호를 여러 번 틀렸더니 로그인이 안 돼요.**
보안을 위해 10분 동안 8회까지만 시도할 수 있습니다. 잠시 후 다시 시도해 주세요.

**Q. 협회 소개글이나 회원사 정보를 바꾸고 싶어요.**
그 부분은 게시판이 아니라 홈페이지 본문 영역이라 제작사(이이공이)를 통해 수정합니다.
납품 후 1개월 이내의 자료 반영은 하자보수 범위에서 처리해 드립니다.
