## 0. 이 작업이 무엇인가

**사단법인 한국온라인해외직판협회(KODSA)의 원페이지 랜딩페이지 시안**을 만듭니다.

- 콘텐츠와 정보구조(IA)는 **확정**입니다. 아래 §4의 섹션 순서와 원고를 그대로 씁니다.
- 확정되지 않은 것은 **비주얼 언어**뿐입니다. 타이포그래피, 팔레트, 레이아웃 구성, 모션.
- 즉 그린필드 리디자인입니다. 콘텐츠 보존, 비주얼은 백지.

### Design Read
> **B2B 성격의 비영리 협회 랜딩. 관객은 해외진출을 검토 중인 소상공인·중소기업 대표와 정부·지자체 담당자. 신뢰가 먼저이고 성장 서사가 그다음인 언어. Tailwind 유틸리티 + 한국어 전용 타이포 스택 + 절제된 스크롤 모션으로 간다.**

### 다이얼

| 다이얼 | 값 | 근거 |
|---|---|---|
| `DESIGN_VARIANCE` | **6** | 재무고시 게시 의무가 있는 사단법인이라 기관 신뢰도가 상한을 만듭니다. 다만 회원사 모집이 목적인 마케팅 페이지이므로 공공기관 수준(3-4)까지 내리지 않습니다. 비대칭은 쓰되 실험적이지 않게. |
| `MOTION_INTENSITY` | **4** | 관객에 50-60대 사업주와 공무원이 포함됩니다. 진입 트랜지션 + 스크롤 리빌까지만. 스크롤 하이재킹, 마그네틱 물리, 커서 추적은 금지. |
| `VISUAL_DENSITY` | **4** | 읽을 원고가 꽤 있습니다(인사말이 8문단). 갤러리처럼 비우면 페이지가 과하게 길어집니다. |

> 다이얼을 올리고 싶은 유혹이 있을 겁니다. 참으세요. 이 협회의 경쟁 상대는 Awwwards 사이트가 아니라 KOTRA·중소벤처기업부 페이지입니다. **화려함이 아니라 "이 단체는 실재하고 신뢰할 만하다"가 이겨야 할 지점입니다.**

## 1. 협회는 어떤 곳인가

- 국내 상품을 해외 소비자에게 **직접 판매(해외직판)** 하도록 지원하는 사단법인
- 플랫폼 입점이 아니라 **현지화 자사몰** 모델을 확산시키는 것이 차별점
- **일본 시장을 시작점**으로 세계 시장까지 확장
- 비전: **"10만 해외직판상 양성"**
- 회장: **권대욱**
- 교육에서 끝나지 않고 실제 판매까지 가는 **"실행형 협회"** 를 스스로 강조

### 톤
- ❌ 스타트업 마케팅 톤("혁신", "게임체인저", "함께 성장해요")
- ❌ 관공서 공고문 톤(딱딱한 고지형 문체)
- ✅ **확신에 찬 산업 단체 톤.** 주장이 분명하고, 근거를 대고, 과장하지 않음

## 2. 한국어 타이포그래피 — 가장 중요한 제약

**taste-skill의 폰트 추천 풀(Geist, Satoshi, Cabinet Grotesk, PP Neue Montreal 등)은 전부 한글 글리프가 없습니다.** 그대로 쓰면 한글이 시스템 폰트로 폴백되어 시안이 무너집니다. 이 프로젝트에서는 아래 스택으로 대체합니다.

### 권장 스택

| 용도 | 폰트 | 비고 |
|---|---|---|
| 본문 + 기본 | **Pretendard** | 한국어 웹의 사실상 표준. 자간·장평이 안정적 |
| 디스플레이(헤드라인) | **Wanted Sans** 또는 **SUIT** | Pretendard보다 인상이 강해 헤드라인에서 구분됨 |
| 숫자·라벨 | **Pretendard** 의 `tabular-nums` 또는 **IBM Plex Mono**(라틴 전용 구간만) | "10만", 연도 등 |

- 한 프로젝트에 **하나의 한글 패밀리**만. Pretendard + Noto Sans KR 혼용 금지.
- 클로드 디자인에서 웹폰트 로딩이 어려우면 `system-ui, -apple-system, "Malgun Gothic"` 으로 대체하되, **시안 노트에 의도한 폰트를 명시**하세요.

### 한글 조판 규칙 (필수)
- `word-break: keep-all` — 한글 단어가 음절 단위로 쪼개지는 것 방지. **이거 빠지면 헤드라인이 깨집니다.**
- 본문 `line-height: 1.7~1.8`. 라틴보다 넉넉해야 합니다.
- 디스플레이 자간 `letter-spacing: -0.02em ~ -0.03em`. 한글은 라틴보다 조금 더 조여야 단단해 보입니다.
- **한글에 serif 쓰지 마세요.** taste-skill의 serif 경고가 한글에서는 더 강하게 적용됩니다. 한글 명조는 화면에서 가독성이 떨어지고 즉시 "관공서 인쇄물" 인상을 만듭니다.

## 3. 팔레트 — 3개 방향 중 택1 (시안은 3개 다 뽑기)

AI 기본값인 **보라/블루 글로우 그라디언트는 금지**입니다. 아래 3방향을 각각 시안으로 뽑아 비교합니다.

### A. Institutional Cobalt (권장)
```
배경   #FFFFFF / #F5F7FA (섹션 구분)
잉크   #12161C (순수 검정 아님)
액센트 #1B54D6 (코발트)
보조   #E8EDF6
```
기관 신뢰 + 현대적. "수출·글로벌"의 관습적 연상과 맞으면서 흔한 SaaS 블루보다 채도가 낮고 단단합니다.

### B. Deep Navy + Signal Orange
```
배경   #FFFFFF / #F6F8FB
잉크   #0A2540 (딥네이비)
액센트 #FF6B35 (시그널 오렌지, CTA 전용)
보조   #EEF4FB
```
네이비가 신뢰를, 오렌지가 "실행형"의 에너지를 담당. 오렌지는 **CTA에만** 쓰고 장식으로 흘리지 마세요.

### C. Ink + Vermilion
```
배경   #FAFAF8
잉크   #1A1A1A (먹)
액센트 #D4402A (주홍)
보조   #EDEAE4
```
한국적 뉘앙스를 색으로만 암시. 단청·태극 같은 **직접적 모티프는 쓰지 마세요.** 촌스러워집니다.

### 공통 규칙
- **액센트는 1개.** 페이지 전체에서 동일하게. 7번 섹션에서 갑자기 다른 색 CTA가 나오면 실패.
- 순수 `#000000` / `#ffffff` 금지.
- 라운드 스케일 **하나만** 정해서 끝까지. (권장: 카드 12px / 버튼 8px / 입력 8px — 정했으면 예외 없이)
- 라이트 모드 고정. 협회 사이트에 다크모드 토글은 불필요합니다.

## 4. 섹션 구성 — 레이아웃 패밀리를 미리 배정

taste-skill의 **"8개 섹션이면 최소 4개의 서로 다른 레이아웃 패밀리"** 규칙을 만족시키기 위해 미리 배정합니다. 같은 패밀리를 두 번 쓰지 마세요.

| # | 섹션 | 레이아웃 패밀리 | 핵심 |
|---|---|---|---|
| 1 | Hero | **Asymmetric Split** | 좌측 헤드라인 / 우측 실사 이미지. 중앙정렬 금지 |
| 2 | 협회소개 | **Sticky 2-col Editorial** | 좌측 제목 고정, 우측 본문 스크롤 |
| 3 | 6대 사업 | **Bento Grid (리듬 있게)** | ⚠️ **3열 동일 카드 절대 금지** |
| 4 | 비전 10만 | **Full-bleed Statement Band** | 숫자 하나가 화면을 지배 |
| 5 | 협회장 인사말 | **Offset Portrait + Prose** | 인물 + 긴 글. 2번과 다른 구성으로 |
| 6 | 성공사례 | **Card Grid (이미지 우선)** | 회원사 10곳, 일본 자사몰 링크 |
| 7 | 아카데미 / 포럼 | **2-up Panel** | 좌우 대칭 패널 2개 |
| 8 | 협회소식 | **List Rows** | 기능적으로. 꾸미지 말 것 |
| — | Footer | 기관 정보 블록 | |

### ⚠️ 3번 섹션 주의
6대 사업을 **3×2 동일 카드 그리드로 만들지 마세요.** taste-skill이 명시적으로 금지하는 패턴이고, 실제로 AI 랜딩페이지의 1번 텔입니다. 대안:
- 첫 사업(전문인재 양성)을 큰 셀로, 나머지 5개를 작은 셀로 → 비대칭 벤토
- 2+2+2 로 나누되 각 행의 셀 비율을 다르게
- **셀 6개 중 최소 2-3개는 시각적 변주**(이미지, 패턴, 톤 배경)를 넣을 것. 흰 배경에 텍스트만 6개면 실패

### 아이브로우 예산 — **최대 3개**
섹션 9개 기준 `ceil(9/3) = 3`. 지금 개발된 버전은 `ABOUT` `VISION` `CHAIRMAN'S MESSAGE` `SUCCESS CASES` `ACADEMY` `FORUM` `NEWS` 로 **7개를 쓰고 있어 규칙 위반입니다.** 시안에서는 3개 이하로 줄이세요. 헤드라인만으로 충분한 섹션이 대부분입니다.

### 중간점(`·`) 주의
한국어 UI는 중간점을 남발하기 쉽습니다(`협회소식 · 공지사항 · 재무고시`). **한 줄에 1개까지.** 그 이상 필요하면 줄바꿈이나 컬럼으로 분리하세요.

## 5. 확정 원고 (그대로 사용, 로렘입숨 금지)

### Hero
- 아이브로우: `KODSA · 사단법인 한국온라인해외직판협회`
- 헤드라인: **대한민국의 다음 수출은 해외직판입니다.**
- 서브: 국내의 우수한 상품이 세계 소비자와 직접 연결되도록, 교육에서 끝나지 않고 실제 판매까지 함께 만드는 실행형 협회입니다.
- CTA: `협회 소개 보기` (주) / `성공사례 보기` (부)

> Hero 규칙: 헤드라인 최대 2줄, 서브 20단어 이내, CTA가 스크롤 없이 보일 것, 상단 패딩 `pt-24` 이하. 텍스트 요소는 최대 4개(아이브로우/헤드라인/서브/CTA). 신뢰 로고 스트립이나 작은 태그라인을 히어로에 밀어넣지 마세요.

### 협회소개
1. 국내시장은 빠르게 변화하고 있습니다. 치열한 경쟁과 소비 둔화 속에서 많은 소상공인과 중소기업은 새로운 성장의 길을 찾고 있습니다.
2. 한국온라인해외직판협회는 이러한 변화 속에서 해외 소비자에게 직접 판매하는 해외직판을 대한민국의 새로운 성장 전략으로 제시합니다.
3. 우리는 단순히 상품을 해외에 판매하는 방법을 교육하는 단체가 아닙니다. 국내의 우수한 상품이 세계 소비자와 직접 연결될 수 있도록 여섯 가지 사업을 통해 실질적인 성과를 만드는 실행형 협회입니다.

강조 블록: 특히 일본 시장을 시작으로 세계 시장까지 이어지는 현지화 자사몰 해외직판 모델을 확산하여, 대한민국 기업의 지속 가능한 글로벌 경쟁력을 만들어가고 있습니다.

1. 안녕하십니까. 한국온라인해외직판협회 회장 권대욱입니다.
2. 대한민국에는 세계 어디에 내놓아도 경쟁력 있는 제품과 기술이 많습니다. 그러나 아직도 많은 기업과 소상공인은 국내시장이라는 좁은 울타리 안에서 치열한 경쟁을 이어가고 있습니다.
3. 이제 시선을 세계로 돌려야 합니다. 인터넷과 AI의 발전은 국경의 의미를 바꾸고 있습니다. 이제 세계시장은 일부 대기업만의 무대가 아닙니다. 누구나 자신의 브랜드와 상품으로 세계 소비자를 만날 수 있는 시대가 열렸습니다.
4. 해외직판은 선택이 아니라 새로운 기회이며, 대한민국 경제의 새로운 성장동력이 될 것입니다.
5. 물론 혼자서는 쉽지 않습니다. 시장조사, 자사몰 구축, 현지화, 마케팅, 물류, 고객서비스까지 준비해야 할 일이 많습니다. 그래서 경험과 협력이 필요합니다.
6. 한국온라인해외직판협회는 단순히 교육하는 단체가 아닙니다. 회원들과 함께 배우고, 함께 실행하고, 함께 성장하는 실행 공동체가 되겠습니다. 교육에서 끝나지 않고 실제 판매가 이루어지고, 성공 사례가 이어지고, 세계시장에 도전하는 기업이 계속 탄생하도록 최선을 다하겠습니다.
7. 우리의 꿈은 분명합니다. 대한민국 10만 해외직판상을 양성하여 세계를 시장으로 만드는 것. 그 길이 대한민국 경제를 살리고, 소상공인과 중소기업의 미래를 여는 길이라고 믿습니다.
8. 그 길에 여러분과 함께하겠습니다. 감사합니다.

서명: `한국온라인해외직판협회 회장` / `권대욱`

## 6. 이미지 계획

taste-skill은 텍스트만 있는 페이지를 미완성으로 봅니다. 이미지를 반드시 넣되, 아래 구분을 지키세요.

### 생성해도 되는 것
| 위치 | 방향 |
|---|---|
| Hero | 일본 가정/상점에서 한국 제품이 쓰이는 장면, 또는 포장·출고 현장의 손 클로즈업. **지구본·비행기·컨테이너선 스톡 클리셰 금지** |
| 6대 사업 벤토 2-3셀 | 교육 현장, 노트북 위 자사몰 화면, 미팅 장면 등 |
| 성공사례 카드 10장 | 화장품·식품·생활잡화 등 K-제품 상품컷. 실제 브랜드 로고는 넣지 말 것 |

### 생성하면 안 되는 것
- **협회장 권대욱 님의 얼굴 사진.** 실존 인물입니다. AI로 얼굴을 만들어 넣으면 안 됩니다. 인물 사진 자리는 **빈 프레임 + `[협회장 사진 제공 예정]` 라벨**로 처리하고, 레이아웃이 사진 비율(4:5 권장)을 잡아두기만 하세요.
- **실제 회원사의 로고나 상호.** 명단 미수령 상태입니다. 카드에는 `회원사명 (확정 예정)` 또는 중립적 가상 브랜드명을 쓰되, **가상임이 드러나게** 하세요.

### 금지
- div로 만든 가짜 스크린샷 / 가짜 대시보드
- 손으로 그린 장식용 SVG 일러스트
- 텍스트 워드마크로 채운 "신뢰 로고월"

### 규칙상 걸리지만 현 단계에서 해소 불가
- **아이브로우 3개 = 상한선.** 히어로(`KODSA · 사단법인…`), `VISION`, `SUCCESS CASES`. 섹션이 더 늘어나면 상한도 올라가지만, 지금은 여유가 없으니 새 섹션을 추가할 때 아이브로우를 붙이지 마세요.
- **실사진 없음.** picsum 임시 사진은 협회·제품과 무관합니다. 협회에 보여줄 때 "사진은 배치 확인용"이라고 반드시 함께 전달하세요.
- **모션은 CSS 스크롤 기반 애니메이션**(`animation-timeline: view()`)으로 구현했습니다. 미지원 브라우저(구형 Safari 등)에서는 애니메이션 없이 처음부터 보이는 상태로 폴백되며, 이는 의도된 동작입니다.
