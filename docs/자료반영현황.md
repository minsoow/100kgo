## 2. 확인이 필요한 사항

### 2-1. 협회장 사진 — 정식 촬영본으로 교체 완료 (2026-08-26)

기존에 받았던 **세바시(SEBASI) 강연자 프로필 카드**는 타 기관 로고·직함이 들어 있어
인물 영역만 잘라 쓰고 있었습니다. 이번에 받은 스튜디오 촬영본(620 × 930)으로 **전면 교체**했습니다.

- 자르지 않고 원본 전체를 사용했습니다. 크기만 2배로 키웠습니다.
- 인물이 프레임의 y 92~877 을 채워 기존 4:5 슬롯으로는 머리 위 여백이 사라지거나
  팔짱 낀 손이 잘렸습니다. **표시 슬롯을 원본 비율(2:3)에 맞췄습니다.**
- 세바시 저작권 확인 건은 **해소**되었습니다.

**남은 확인 사항**
1. 직함이 "이사장"인지 "**협회장**"인지 알려 주세요. 현재는 "회장"으로 표기 중입니다.
2. 원본 해상도가 620 × 930 으로 크지 않습니다. 화면에는 문제없지만 여유 있는 원본이 있으면 더 선명해집니다.

### 2-2. 로고 — 어두운 배경용 버전이 있으면 좋습니다

로고가 남색 + 초록 컬러라 어두운 배경(히어로 위 투명 내비, 푸터)에서 대비가 떨어집니다.
현재는 **흰색 단색으로 자동 반전**해 표시하고 있습니다(밝은 배경에서는 원본 컬러 그대로).

- 흰색/단색 전용 버전이 있으면 더 정확하게 표현됩니다
- 원본이 AI·SVG 등 벡터 파일이면 어떤 크기에서도 선명합니다 (현재는 PNG)

## 3. 별도 견적이 필요한 신규 요청 — **이이공이 회신 필요**

회신 문서 C절에 협회가 새로 요청한 항목입니다. **계약 범위 밖이라 금액 판단이 필요합니다.**

### 3-1. 이벤트·행사 공지용 팝업 — **방침 확정됨 (통화)**

- **1차: 무상 1회성 제작.** 이번 행사 공지는 코드로 직접 넣어 드립니다.
- **2차: 유료 추가개발.** 이후 협회가 직접 등록·수정하길 원하면 팝업 관리 CMS를 별도 견적.

> 1회성으로 만들 때도 데이터 구조(제목 · 본문 · 이미지 · 링크 · 노출기간 · "오늘 하루 보지 않기")를
> 미리 잡아두면, 나중에 CMS로 올릴 때 화면을 다시 만들 필요가 없습니다.

**제작에 필요한 것** — 아래를 주시면 바로 넣겠습니다.

| 항목 | 비고 |
|---|---|
| 팝업 제목 | |
| 본문 문구 | 짧게 |
| 이미지 | 있으면. 권장 가로 600px 내외 |
| 연결 링크 | 클릭 시 이동할 주소 (없으면 닫기만) |
| 노출 기간 | 시작일 ~ 종료일 |
| 노출 페이지 | 첫 화면만 / 전체 페이지 |

### 3-2. 개발 소스코드 제공

현 견적서에는 소스코드 조항이 없습니다. **"소스 제공"과 "저작권 양도"는 다른 계약**이므로 먼저 구분해야 합니다.

| 구분 | 내용 | 통상 수준 (개발비 대비) |
|---|---|---|
| ① 소스 제공 (사용권) | 코드를 넘기되 저작권은 제작사 보유. 협회는 자체 운영·수정만 가능 | 0 ~ 20% |
| ② 저작권 양도 | 협회가 저작권까지 보유. 2차 활용·재배포 가능 | 30 ~ 50% |

**이 프로젝트(개발비 100만원, VAT 별도) 기준 참고선**

- ① 소스 제공만 → **무상 ~ 20만원**
- ② 저작권 양도 포함 → **30만 ~ 50만원**

> 위 비율은 업계에서 흔히 쓰이는 범위이며 법정 기준이 아닙니다. 최종 금액은 협의 사항입니다.

**판단 시 고려할 점**

- 이 사이트는 협회 전용으로 만든 맞춤 코드라 재판매 가치가 크지 않습니다.
- 이미 협회 소유 Vercel·도메인 위에서 돌아가므로, 소스를 안 넘긴다고 해서 협상력이 생기지 않습니다.
- 오히려 소스를 제공하면 "업체 종속이 없다"는 신뢰 요소가 되어 후속 발주에 유리할 수 있습니다.

**계약서에 반드시 넣을 조항**

1. 제3자 오픈소스 라이브러리는 각 라이선스가 그대로 적용되며 양도 대상이 아님
2. 이이공이의 내부 공통 코드·노하우는 제외
3. 소스 이관 시점부터 **하자보수(1개월) 책임 종료**
4. 이관 후 협회가 수정한 코드로 발생한 문제는 책임 범위 밖
5. 인수인계 산출물 범위 명시 (저장소 · 환경변수 목록 · 빌드/배포 절차)

## 3-3. 도메인 연결 (DNS) 절차

도메인 `www.100kgo.kr` · 웹호스팅 없음.

> ⚠️ **네임서버가 후이즈입니다.** 2026-08-28 조회 결과 `100kgo.kr` 의 네임서버가
> `ns1~ns4.whoisdomain.kr` 로 잡혀 있습니다. **DNS 레코드는 네임서버를 관리하는
> 곳에서 넣어야 합니다.** 예스닉 관리화면에 DNS 레코드 입력란이 없으면
> 후이즈(whois.co.kr) 계정에서 넣어야 합니다.

> ⚠️ **아래에 고정된 레코드 값을 적지 않습니다.** Vercel 은 이제 프로젝트마다
> 고유한 CNAME 을 발급합니다(예: `d1d4fc829fe7bc7c.vercel-dns-017.com`).
> 예전에 쓰이던 `cname.vercel-dns.com` · `76.76.21.21` 을 그대로 넣으면
> 연결되지 않습니다. **반드시 Vercel 화면에 표시되는 값을 그대로** 쓰세요.

### 1단계 — Vercel 에 도메인 추가
프로젝트 `100kgo` → **Settings → Domains** → **Add Domain** → `www.100kgo.kr`

apex(`100kgo.kr`)도 함께 추가할지 물어봅니다. 함께 추가하고 **www 를 대표 주소**로
둡니다(`NEXT_PUBLIC_SITE_URL` 이 www 기준). apex 는 www 로 자동 전환됩니다.

추가하면 화면에 **넣어야 할 레코드가 표시됩니다.** 이 값을 그대로 복사하세요.
보통 www 는 CNAME, apex 는 A 레코드입니다.

### 2단계 — 네임서버 관리처에서 레코드 등록
후이즈(또는 예스닉) → 도메인 관리 → **DNS 레코드 관리**

Vercel 화면의 값을 그대로 입력합니다. TTL 은 기본값이면 됩니다.

### 3단계 — 반영 확인
```
nslookup www.100kgo.kr
```
Vercel Domains 화면의 도메인 옆이 **Valid Configuration** 으로 바뀌면 완료입니다.
보통 10분~수 시간, 최대 24~48시간. HTTPS 인증서는 Vercel 이 자동 발급합니다.

### 4단계 — 마지막에 검색 노출 열기
연결이 확인된 **뒤에** Vercel 환경변수에 `NEXT_PUBLIC_ALLOW_INDEXING` = `1` 을
추가하고 **Redeploy** 합니다.

색인은 기본 차단이라, 이 단계를 빠뜨리면 사고가 나는 게 아니라 검색에만
안 잡힙니다. 확인:
```
curl -s https://www.100kgo.kr/robots.txt
```
`Allow: /` 가 나와야 정상입니다.
