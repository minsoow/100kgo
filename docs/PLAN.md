## 2. 두 문서 간 차이 — 착수 전 정리 필요

| # | 쟁점 | 견적서 | 기획안 | 제안 |
|---|---|---|---|---|
| A | 게시판 용도 | **재무고시** 게시용 | **협회소식/공지사항** | 게시판 1개에 `카테고리` 필드(공지사항 / 재무고시)를 두어 탭으로 분리. 개발 물량은 게시판 1개 그대로 유지 |
| B | 연혁 섹션 | 섹션 예시에 포함 | 원고 없음 | 연혁 원고 제공 여부 확인. 미제공 시 섹션 제외 |
| C | 성공사례 관리 | 언급 없음 | 초기 10개사, 이후 증가 전제 | 아래 3절 참고 — 이번 범위는 **정적 데이터**로 구축 |

### 성공사례 섹션 처리 방침 (중요)
기획안상 회원사(회사명·취급품목·일본 자사몰 URL·로고·대표상품 이미지)는 앞으로 계속 늘어날 항목이지만,
견적 범위의 CMS는 **게시판 1개**뿐입니다. 따라서:

- **이번 범위**: 협회가 전달한 10개사를 데이터 파일로 구성 → 카드/버튼 그리드로 출력
- **추가 등록 방법**: 하자보수 기간(1개월) 내 자료 추가는 무상 반영, 이후는 건별 협의
- **선택지**: 회원사도 협회가 직접 관리하고 싶다면 → **회원사 관리 CMS 추가 개발(별도 견적)**

착수 전에 협회 측 의사를 확인해 계약서에 명시하는 것을 권장합니다.

## 3. 사이트 구조 (IA)

### 원페이지 (`/`) — 상단 GNB는 앵커 스크롤
| 순서 | 섹션 | 앵커 | 내용 |

| 0 | Hero | – | 헤드라인 "대한민국의 다음 수출은 해외직판입니다." + 핵심 CTA |
| 1 | 협회소개 | `#about` | 협회 정체성 + 6대 사업(전문인재 양성 / 자사몰 구축·운영 지원 / AI 글로벌 마케팅 / 해외시장 정보 / 정부·지자체 정책 협력 / 회원사 네트워크) 아이콘 카드 |
| 2 | 비전 | `#vision` | "10만 해외직판상 양성" — 숫자 강조 배너 |
| 3 | 협회장 인사말 | `#greeting` | 회장 권대욱 인사말 전문 + 사진/서명 |
| 4 | 현지화 자사몰 성공사례 | `#cases` | 회원사 카드 10개 (로고 · 회사명 · 취급품목 · 대표상품 이미지 · 일본 자사몰 바로가기 버튼) |
| 5 | 해외직판아카데미 | `#academy` | 소개 + 네이버 카페 링크 (`cafe.naver.com/kbbsacademy`) |
| 6 | 해외직판포럼 | `#forum` | 소개 + 네이버 카페 링크 (`cafe.naver.com/f-e/cafes/30902180/menus/62`) |

## 4. 기술 구성 (권장안)

**Next.js 15 (App Router, TypeScript) + Tailwind CSS + PostgreSQL + Vercel 배포**

| 영역 | 선택 | 근거 |
|---|---|---|
| 프레임워크 | Next.js 15 / React / TypeScript | 원페이지 + 게시판을 한 코드베이스로. SEO용 SSR 기본 제공 |
| 스타일 | Tailwind CSS | 반응형 대응 속도 |
| DB | Neon PostgreSQL (서버리스) | 무료 티어, 미사용 시 자동 슬립 → **자동 재개**. 월 고정비 0 |
| ORM | Drizzle ORM | 스키마 단순, 마이그레이션 관리 용이 |
| 파일 저장 | Vercel Blob (PDF·이미지) | 첨부파일 CDN 서빙. 무료 할당량 내 운용 |
| 인증 | Auth.js Credentials + bcrypt (단일 관리자 계정) | 요구사항이 "담당자 로그인" 1인 수준 |
| 에디터 | Tiptap (또는 Toast UI Editor) | 한글 지원, 붙여넣기 안정, HTML sanitize |
| 배포 | Vercel + 기존 도메인 DNS(CNAME) 연결 | 호스팅 서버 관리 불필요 = 월 관리비 없는 견적 조건과 부합 |

### 대안 (협회 상황에 따라)
- 협회가 **카페24/가비아 웹호스팅을 이미 보유**하고 그곳에 올려야 한다면 → WordPress(원페이지 테마 + KBoard) 또는 정적 퍼블리싱 + PHP 게시판으로 전환.
  → 다만 WordPress는 보안 업데이트가 상시 필요해 **"월 유지보수 없음"** 조건과 상충. 권장하지 않음.
- **착수 전 확인 필수**: 현재 도메인 등록기관, 기존 호스팅 계약 유무, DNS 관리 권한 보유자.

### DB 스키마 (초안)
```
posts        id, category('notice'|'finance'), title, content, is_pinned,
             view_count, created_at, updated_at
attachments  id, post_id, file_name, file_url, file_size, mime_type
admin_users  id, username, password_hash, created_at
```

### 보안·품질 기준
- 관리자 로그인 rate limit, 세션 쿠키 httpOnly/secure
- 업로드 확장자 화이트리스트(pdf, jpg, png, hwp) + 용량 제한(20MB)
- 에디터 입력 HTML sanitize (XSS 차단)
- HTTPS 강제, 이미지 최적화(next/image), Lighthouse 성능/접근성 90점 이상 목표
- Open Graph 태그·favicon·sitemap.xml 기본 세팅 (※ SEO "마케팅"은 범위 외, 기본 메타태그만 포함)

| 주차 | 기간 | 작업 | 협회 측 할 일 |

| **1주 전반** | D+1~3 | IA·와이어프레임 확정, 디자인 컨셉 제안 | **원고·이미지 전달 (6절 체크리스트)** |
| **1주 후반** | D+4~7 | 디자인 시안 1차 제출 | 시안 피드백 (수정 1회차) |
| **2주 전반** | D+8~11 | 시안 확정 → 반응형 퍼블리싱 | – |
| **2주 후반** | D+12~15 | 게시판 개발(공개 화면 + 관리자 CMS + 파일 업로드) | – |
| **3주 전반** | D+16~18 | 콘텐츠 반영, 도메인 연결, 크로스브라우징 QA | 최종 검수 (수정 2회차) |

일정 기산점은 "착수일"이 아니라 **"자료 전달 완료일"** 로 계약서에 명시할 것을 권장합니다.

## 8. 착수 전 확인 사항 (협회에 회신 요청)

1. 게시판을 **공지사항 + 재무고시 2개 카테고리**로 구성하는 것으로 확정 가능한지
2. **연혁 섹션** 포함 여부 및 원고 제공 가능 여부
3. **회원사(성공사례) 추가 등록**을 협회가 직접 하기를 원하는지 → 원할 경우 별도 견적 진행
4. 기존 **도메인/호스팅** 보유 현황 및 DNS 관리 권한
5. 협회 가입 문의 창구 필요 여부 (문의 폼 / 이메일 링크 / 네이버 카페 중 택1)
   - 문의 **폼** 개발은 견적 범위 밖 → 이메일 링크 또는 카페 링크 권장
